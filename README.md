balao magico: pode ter 2 ou 3 cortes de intervalos.

a lista fica:

prePos
bloco 1
intervalo
bloco 2
intervalo
bloco 3
prePos

programa balao magico tem os anexos:
prePos
intervalo

o anexo referente aos desenhos devem ser:

bloco1: [sooby-doo,super amigos,x-men]
bloco2: [caverna do dragao,he-man,thundercats]

entao, os anexos ficarao assim
prePos:string,
intervalo:string,
bloco1: [string,string]
bloco2: [string,string]

e a lista final vai ficar:

prePos
bloco1
anexo.bloco1[0]
anexo.bloco1[1]
anexo.bloco1[2]
intervalo
bloco2
anexo.bloco2[0]
anexo.bloco2[1]
anexo.bloco2[2]
intervalo
bloco3
prePos

Quantidade fechada de intervalos por programa
lista de anexos de blocos devem ser no maximo a quantidade de intervalos
